# Frontend Design Skill Overview

This skill enables creation of distinctive, production-grade frontend interfaces with high design quality. It's appropriate when users request web components, pages, dashboards, React components, HTML/CSS layouts, or UI beautification.

## Core Principles

The approach emphasizes avoiding generic "AI slop" aesthetics through intentional design thinking:

**Before coding**, establish a clear aesthetic direction by understanding purpose, selecting a distinctive tone (from brutalist to maximalist), identifying constraints, and determining what makes the design memorable.

**During implementation**, the code should be production-ready while being "visually striking and memorable" with a cohesive aesthetic point-of-view.

## Key Design Focus Areas

- **Typography**: Use "distinctive choices that elevate the frontend's aesthetics" rather than generic options
- **Color & Theme**: Commit to cohesive palettes using CSS variables for consistency
- **Motion**: Prioritize impactful animations, particularly "staggered reveals" during page load
- **Composition**: Employ asymmetry, overlap, and grid-breaking layouts
- **Details**: Add contextual effects like gradient meshes, textures, and decorative elements

## What to Avoid

The guidelines explicitly warn against "overused font families," "cliched color schemes," "predictable layouts," and "cookie-cutter design that lacks context-specific character." Each design should be contextually unique rather than following common patterns.

The skill emphasizes that "elegance comes from executing the vision well," with complexity matched to the aesthetic approach.
